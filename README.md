# 📊 My Money - Personal Finance Tracker

This is a modern, responsive Personal Finance Dashboard built with **React** and **Vite**. It allows users to track their daily incomes and expenses, visualize their spending habits by category, and keep data persistent using local storage.

🚀 Developed as part of a YouTube tutorial!

## ✨ Features
* **Add Transactions:** Record new incomes or expenses with details (Description, Amount, Category, and Date).
* **Automated Calculations:** Real-time generation of Total Income, Total Expenses, and Net Balance.
* **Category Breakdown:** Categorized analysis of expense distributions.
* **Data Persistence:** Uses `localStorage` to save your transactions, so data isn't lost on page refresh.
* **Responsive Design:** Clean and simple dashboard layout optimized for modern browsers.

## 🛠️ Tech Stack
* **Frontend Framework:** React (Functional Components & Hooks like `useState`, `useEffect`)
* **Build Tool:** Vite
* **Styling:** Custom CSS
* **Storage:** Web Local Storage API

## 🚀 How to Run Locally

Follow these quick steps to get the project running on your computer:

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```

2. **Navigate into the project directory:**
   ```bash
   cd my-react-app
   ```

3. **Install the dependencies:**
   ```bash
   npm install
   ```

4. **Start the development server:**
   ```bash
   npm run dev
   ```

5. Open your browser and navigate to `http://localhost:5173`.
